# Opening book sources

The position-keyed book in `opening_book.c` is generated by
`tools/gen_opening_book.py` from:

1. **[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings)**
   (CC0). TSV files are vendored under `tools/data/chess-openings/` at the
   commit in `tools/data/chess-openings/PIN` (`a6189a30…`, 2026-10-09).
2. **Lichess opening explorer** move weights (`explorer.lichess.org/lichess`,
   `lichess` DB, ratings 1600–2200), cached in
   `tools/data/opening_explorer_cache.json`.

The generator picks several dozen mainstream mainlines (6–10 plies) from the
TSV set, adds short reply coverage for both colors and odd White first moves,
and assigns per-node move weights from the cache (top four moves per position).

## Explorer cache snapshot

| Field | Value |
|---|---|
| Snapshot date | 2026-10-09 |
| `api_reachable` | `false` (HTTP 401 from generator host) |
| `primary_source` | `curated_fallback` |
| Fallback | Documented mid-rating popularity ratios in `tools/fetch_opening_explorer_cache.py` |

Regenerate the cache when online:

```bash
python3 tools/fetch_opening_explorer_cache.py
```

Then rebuild the book:

```bash
python3 tools/gen_opening_book.py
python3 tools/validate_opening_book.py
```

Host validation uses [python-chess](https://github.com/niklasf/python-chess)
(GPL, test-only; see `docs/sources.md`). Firmware does not link python-chess.
