# Opening book sources

The position-keyed book in `opening_book.c` is generated by
`tools/gen_opening_book.py` from:

1. **[lichess-org/chess-openings](https://github.com/lichess-org/chess-openings)**
   (CC0). TSV files are vendored under `tools/data/chess-openings/` at the
   commit in `tools/data/chess-openings/PIN` (`a6189a30…`, 2026-10-09).
2. **Lichess opening explorer** move weights (`explorer.lichess.ovh/lichess`,
   `lichess` DB, ratings 1600–2200), cached in
   `tools/data/opening_explorer_cache.json`.

The generator picks several dozen mainstream mainlines (6–10 plies) from the
TSV set, adds short reply coverage for both colors and odd White first moves,
and assigns per-node move weights from the cache (top four moves per position).

## Explorer cache snapshot (2026-10-09)

| Field | Value |
|---|---|
| Positions | 115 (all `lichess_explorer`) |
| Ratings | 1600, 1800, 2000, 2200 |
| `api_reachable` | `true` |
| Endpoint | `https://explorer.lichess.ovh/lichess` |

Fetched with a personal Lichess API token (Bearer). **Do not commit tokens.**
To refresh on a machine that has access:

```bash
export LICHESS_API_TOKEN=…   # lichess.org account → API access token
python3 tools/fetch_opening_explorer_cache.py
```

The fetch script rate-limits (~1.1 s between requests) and backs off 60 s on
HTTP 429. If the API is unreachable and no valid cache is checked in, the
script can still fall back to documented ratios in
`tools/opening_explorer_fallback.py` (keys derived via python-chess from move
prefixes; not used for the current snapshot). CI runs
`tests/test_opening_fallback.py` on the offline path.

### …c6 after 1.e4 (excluded by the four-move cap)

The explorer snapshot after **1.e4** (ratings 1600–2200) includes roughly:

| Reply | Share of games |
|---|---:|
| …e5 | 30.46% |
| …c5 | 22.80% |
| …e6 | 12.04% |
| …d5 | 10.74% |
| …c6 | 8.97% |

The generator keeps the top **four** moves by count at each node. After **1.e4**
that set is **…e5 / …c5 / …e6 / …d5** (normalized weights **100 / 75 / 40 / 35**
in `opening_book.c`). **…c6 is not in the table** and cannot be played from
the book at any `book_seed`. Host tests scan many seeds to ensure **…c6** never
appears; **`book_seed == 0` plays …e5** (highest weight).

Regenerate the book after cache or line-list changes:

```bash
python3 tools/gen_opening_book.py
python3 tools/validate_opening_book.py
```

Host validation uses [python-chess](https://github.com/niklasf/python-chess)
(GPL, test-only; see `docs/sources.md`). Firmware does not link python-chess.
