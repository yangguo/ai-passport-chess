## M1 功能验收清单

- 从初始局面进行一局本地双人；每一步只呈现合法棋子/落点；白黑交替明确。
- 长按可从升变/落点返回，不改局面；暂停继续、新局覆盖确认、返回首页继续上一局。
- 用户能完成指定e2e4，以及独立完成吃子、易位、升马；观察操作耗时，不预设所有着都只需几次按键。
- 同一设备重启仍保持side、castling、ep、halfmove/fullmove、history与结果；损坏档明确提示、未全擦NVS。
- 三次/50步申报与五次/75步自动终局一致，预选着申报入口可操作；终局后不能继续落子。
- 复杂死局尚未支持时，Release明确列出局限并阻止“完整FIDE规则”宣传；必需的走子与已列和棋门槛不能减项。

证据存 `artifacts/validation/<version>/`（日志/照片不默认入Git，摘要可入docs）；Release附适合公开的摘要与数据。任何NOT RUN保持独立，不能被host PASS或模拟器结果覆盖。发布前从仓库tag重构建，真机使用同一个被核验full文件。

## 2026-10-07 黑屏排障记录

- 根因：设备实际保留原 OTA 分区布局、启动 `ota_0`（`0x20000`），此前 app-only 更新错误地按工程 factory 布局写至 `0x10000`。写入数据校验通过，但启动程序读取的应用并非该镜像。重复 ROM 软件复位和诊断应用无法启动均不能归因于中文字号或 bpp。
- 隔离验证：显示诊断固件来自 GitHub Actions [37568256619](https://github.com/yangguo/ai-passport-chess/actions/runs/37568256619)，host/CLI 与 IDF 构建检查通过。改写至设备实际 `0x20000` 后，串口确认 NVS、LCD、LVGL 初始化成功、背光 80%、测试屏幕已加载，采样期间未继续反复重启。应用分区 digest 验证通过；真实 NVS 及 OTA 元数据与改写前逐字节一致。
- 正常固件：恢复已通过 CI 的 `3a98346` 构建，app SHA256 为 `34f29998a9a738601d82825f3f58a8d729ba103bc35d087a59be68b98cb7478b`，仅写 `ota_0` 的 `0x20000`。写入校验通过，串口确认“象棋应用就绪 gen=2”；用户确认棋盘和暂停菜单正常。
- 正常固件运行及用户操作后再次核验：实际 `0x20000` 应用 digest 与产物一致，OTA 元数据保持一致。NVS 原始字节随 `chess_v1/save_a`、`save_b` 存档更新而变化；比较活动条目确认 `chess_v1` 之外的配置条目逐字节保留，没有擦除共享 NVS。
- 按此前方式重启后的界面验收：用户确认重启后棋盘和暂停菜单均正常。中文清晰度、长时间稳定性与完整功能 gate 仍须独立验收；本记录不代表全部产品验收通过。

## 2026-10-07 中文字体清晰度改进

- 根因证据：上游 Noto Sans SC 可变字体的 `wght` 默认值为 100（Thin）。原 18px/2bpp 字形位图与按该默认值重新生成的结果逐字节一致；仅提高 bpp 不会加粗轮廓。
- 改动：先使用固定版本 FontTools 将轮廓实例化为 `wght=600`（SemiBold），再生成 18px/4bpp 原始字形位图。保持字号及页面布局；行高 21px。86 个本地化中文字形覆盖检查通过，增加代表字笔画不透明度检查；故意使用 Thin 的 4bpp 样本被拒绝。
- 本地：字体覆盖及文档检查 PASS；位图对比中笔画明显加实。该预览不等同于实机视觉验收。
- CI：[37570009022](https://github.com/yangguo/ai-passport-chess/actions/runs/37570009022) 的 host sanitizer、CLI 测试、ESP-IDF v5.5.3 构建及镜像检查全部 PASS。应用代码版本 `1edbd35809afbf15b7c946cab88e82e17e2a6b9f`，app 713,120 bytes，SHA256 `cea96a902d2bc67760c6a165b6b78adb3cb250d426235569bd18327fbbaacb07`。
- 设备：刷写前重新读取实际分区表及 OTA 元数据，确认有效槽为 `ota_0`、地址 `0x20000`、容量 `0x2f0000`。仅更新应用，独立 digest 校验 PASS。串口确认版本 `1edbd35`、LCD/LVGL 及象棋应用就绪；5 秒采样无 panic 或重复 ROM 复位。
- 配置保护：OTA 元数据逐字节不变。NVS 字节随游戏存档更新发生变化；活动条目对比确认变化仅限 `chess_v1/save_a`、`save_b`，非游戏配置活动条目保持一致。
- 实机中文清晰度及按原方式重启后的显示：等待用户反馈，NOT RUN。完整显示/规则/长期稳定性 gate 不由本次字体检查替代。
