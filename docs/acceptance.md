## M1 功能验收清单

- 从初始局面进行一局本地双人；每一步只呈现合法棋子/落点；白黑交替明确。
- 长按可从升变/落点返回，不改局面；暂停继续、新局覆盖确认、返回首页继续上一局。
- 用户能完成指定e2e4，以及独立完成吃子、易位、升马；观察操作耗时，不预设所有着都只需几次按键。
- 同一设备重启仍保持side、castling、ep、halfmove/fullmove、history与结果；损坏档明确提示、未全擦NVS。
- 三次/50步申报与五次/75步自动终局一致，预选着申报入口可操作；终局后不能继续落子。
- 复杂死局尚未支持时，Release明确列出局限并阻止“完整FIDE规则”宣传；必需的走子与已列和棋门槛不能减项。

## 每次验收记录

```text
版本/tag/Git SHA：
固件 SHA256 / full镜像尺寸：
设备型号 / Flash检测 / IDF / BSP / engine SHA：
配置（CPU/亮度/无线/音频/stack/pool）：
host命令/日志/fixture/种子：
干净构建与合并校验日志：
设备测试日期/人员/视频照片/串口证据：
free/min heap、最大块、LVGL峰值、stack最低水位：
输入p95、搜索p95/max、取消p95/max、保存p95/max：
掉电次数/恢复序号与异常：
Gate逐项 PASS/FAIL/NOT RUN + 证据：
限制/问题ID/阻塞/下一动作：
```

证据存 `artifacts/validation/<version>/`（日志/照片不默认入Git，摘要可入docs）；Release附适合公开的摘要与数据。任何NOT RUN保持独立，不能被host PASS或模拟器结果覆盖。发布前从仓库tag重构建，真机使用同一个被核验full文件。
