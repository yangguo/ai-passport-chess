# UI 与三键交互契约

## 布局与视觉

```text
x=0                 240
┌────────────────────┐ y=0
│ 白方走       电量  │ 30px header，文字 x=32..208
├────────────────────┤ y=30
│                    │
│   8 × 8 棋盘       │ 240×240；每格30px
│   双人白下／人机己方下     │
│                    │
├────────────────────┤ y=270
│ 选：e2 兵 → e4     │ 50px footer
│ 上下选择 · OK确认  │ 底行文字保持 x=32..208
└────────────────────┘ y=320
```

格位置：file=square%8，rank=square/8，`x=file*30, y=30+(7-rank)*30`。不在 30px 格外额外占用坐标栏，footer 显示代数坐标。后续翻转仅改变映射，不改变 core 坐标。

配色目标：浅格米白、深格灰蓝；白子亮填充+深轮廓，黑子深填充+亮轮廓。焦点为高对比边框；落点用点标记，吃子用环；将军王格用警告边框；上一着起终点浅色叠加。不能只靠红绿区别状态。

6 个 A8 alpha mask，30×30 共 5400 bytes 原始 Flash 数据；双绘制轮廓或辅小 mask 的实际体积需计入资产清单，不能把 5.4KB 当全部 UI 成本。使用一个自定义棋盘对象，按受影响的格 invalidation；禁止 full-screen canvas。M1 真机确认棋子轮廓、马/象可区分与圆角安全区。

## 状态机

| 状态 | UP/DOWN | OK click | OK long |
|---|---|---|---|
| HOME | 循环继续/新局/人机/语言 | 进入或即时切换语言 | 留在 HOME |
| SELECT_PIECE | 按 square 升序循环有合法着的己方棋子 | 选中进入落点 | 暂停菜单 |
| SELECT_TARGET | 按目标 square 升序循环去重合法落点 | 非升变直接提交；升变进入菜单 | 返回棋子选择 |
| PROMOTION | 后→车→象→马循环 | 提交完整 promotion move | 返回落点，局面不变 |
| THINKING | 不改变棋局 | 无操作，显示思考 | 取消搜索并进入暂停菜单，等待 ACK |
| PAUSE | 循环继续/申报和棋/认输/新对局/返回首页 | 执行或二次确认 | 继续当前局 |
| CONFIRM | 在确认/取消间切换，默认取消 | 执行所选 | 取消 |
| GAME_OVER | 循环新局/复看/返回 | 进入所选 | 返回 HOME |
| ERROR | 错误页选项循环 | 重试/新局 | 返回可用上级页 |

SELECT_TARGET 的升变落点只出现一次，四种走法的选择留给 PROMOTION。选错棋子可长按返回；导航 wrap-around；候选为空时先判终局，不对空数组求模。

短按只消费 BSP CLICK，长按只消费 LONG，不同时用 PRESS+CLICK 执行同一动作；忽略 DOUBLE，实测快速连击是否合并，必要时适配 BSP 成对事件但保持“一次物理单击一次逻辑动作”。同一次按住触发 LONG 后，release CLICK 必须被抑制。初期不做按住连发。

## 和棋、保存、切换

- 暂停菜单显示当前可申报的三次重复/五十步；确认后由 core 重新核验。
- 预选着申报：在 SELECT_TARGET 或 PROMOTION 长按返回后，暂停菜单保留一个“预选着申报”入口及该着显示；核心通过临时 make/unmake 判断，申报成立结束游戏，不提交该着。取消/换焦点即清除预选着，避免误申报。
- 自动终局显示具体原因；将死优先于第150半步自动和棋。其他规则优先级见 core。
- footer 状态优先顺序：终局/错误 > 将军 > 保存状态 > 当前选择/提示。保存失败可继续，但始终标注“未保存”，提供重试。
- 返回首页保留局面；新局或模式切换前停止 AI、保存或明确放弃未保存的修改，再更换 generation。
- 暂停菜单及终局的“新对局”先进入双人／人机选择，选人机再进入难度、执色选择；长按退回上一步，模式选择页长按恢复原局，真正选定模式及执色之前不重置原局。暂停菜单“返回首页”仅返回主菜单。
- 棋子主体使用本方黑／白色，细对比边保证两种背景上可辨；不能让轮廓色占据主要图案、导致视觉反色。
- 人机新局依次选择难度、执白／执黑。执白时白方在下；执黑时棋盘旋转 180°，黑方在下、h1 在左上。显示坐标旋转，规则 square 和着法坐标不变；己方方向整局固定，不随走棋方翻转。
- 所有新局仍白先走。玩家执黑时 AI 自动完成白方开局；AI 搜索期间玩家不能代走。取消搜索进入暂停后，继续对局会重新请求 AI。颜色和难度随存档恢复；在颜色选择页长按返回难度页，不改变当前对局。
- M1 不提供悔棋、棋钟、旋转或复杂动画；悔棋在历史恢复测试完善后加入。

## 可验证体验

测试每种状态的三键、wrap、快速输入、长按 release、升变取消、搜索退出、损坏存档入口。真机让初学者从初始局面下出 e2e4，并独立完成吃子、易位、升马与返回；目标见性能文档。棋子选择最坏可超过几次按键，不承诺任何一着都很快。
